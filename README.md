# Magic Note 课堂笔记原型

在线体验：[GitHub Pages](https://kechangyuan3.github.io/Magic-Notes/) · [原体验站](https://demo-classroom.happymorel8.chatgpt.site/)

GitHub Pages 从 `main` 分支的 `docs/` 文件夹发布。可在 `docs/` 查看网站当前发布文件；`dist/` 保留本次迁移包中的原始发布副本。

浏览器新增的个人笔记、上传文件和录音保存在本机浏览器，不会自动随网站迁移。页面使用浏览器录音与语音服务，是否可用取决于浏览器、网络和麦克风权限；手势模型随站点文件提供。
